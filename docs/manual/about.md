# About XPP Studio

XPP Studio puts a modern interface on the XPPAUT engine and adds a
Python package.

## Credits

- **XPPAUT** by G. Bard Ermentrout, with Daniel Dougherty and Robert
  McDougal, is the engine: the parser, the integrators and the analysis
  tools. Licensed under GPL-2.0-or-later.
  https://sites.pitt.edu/~phase/bard/bardware/xpp/xpp.html
- **AUTO** by Eusebius Doedel and collaborators does the continuation
  (BSD licence), through XPPAUT's C translation.
- **CVODE** (Lawrence Livermore National Laboratory) is one of the
  integrators.
- **Dear ImGui** (Omar Cornut), **ImPlot** (Evan Pezent), cimgui and
  cimplot provide the interface (MIT licence). **SDL** provides windows and
  graphics (zlib licence).
- The fonts are Roboto and Cousine (Apache License 2.0).

If you use XPPAUT's methods in published work, cite Ermentrout's book:
G. B. Ermentrout, *Simulating, Analyzing, and Animating Dynamical Systems:
A Guide to XPPAUT for Researchers and Students*, SIAM, 2002.
